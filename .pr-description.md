# feat(dashboard): enhance header nav with kicker, animated pills and visual hierarchy

## What changed
- **Kicker**: Small blue label above the main title showing the current section (Daily Log, Weekly Recap, etc.). Icon only on Daily Log.
- **Nav pills**: Active tab uses sky-to-indigo gradient, soft glow, and colored icon; inactive pills use subtle glass style with hover.
- **Animated underline**: Framer Motion `layoutId` for smooth tab indicator transition.
- **Notifications button**: Consistent glass styling, compact size (w-9 h-9), badge placeholder for future use.
- **Helpers**: `SECTION_LABELS` constant reused for kicker, title, and nav; placeholder components for unimplemented sections.

## Why
- Restore visual hierarchy (Daily Log in blue) and make navigation feel less flat.
- Improve affordance of active tab and polish without breaking layout.

## How to test
1. Open Dashboard.
2. Switch between Daily Log, Weekly Recap, Stickies, Topics, Settings — kicker and title update; underline animates.
3. Check responsive: horizontal scroll on mobile, pills and notifications button readable.
